SEGURANÇA ANTES DE SUBSTITUIR
1. Na raiz do projeto:
   mv src src-backup

2. Extraia o ZIP na raiz do projeto.
   O ZIP contém a pasta src/.

3. Gere novamente o Prisma Client:
   docker compose exec web npx prisma generate

4. Reinicie:
   docker compose restart web

TESTE DE COMPILAÇÃO / QUALIDADE
5. Rode:
   docker compose exec web npm run build

6. Se package.json tiver scripts de lint/test:
   docker compose exec web npm run lint
   docker compose exec web npm test -- --run

TESTE HTTP PELO TERMINAL
7. Rode:
   docker compose exec web sh -lc '
   for route in / /projects /skills /evidences /showcase /health /api/health; do
     echo "===== $route ====="
     wget -S -O- "http://localhost:3000$route" 2>&1 | head -n 8
     echo
   done
   '
