# Objetivos

## Objetivo principal

Permitir que um desenvolvedor relacione Projeto -> Skill -> Contexto -> Evidência para demonstrar
competências de forma rastreável.

## Objetivos iniciais

- cadastrar e acompanhar projetos;
- catalogar habilidades;
- relacionar habilidades aos projetos em que foram aplicadas;
- registrar evidências;
- registrar decisões arquiteturais;
- oferecer uma superfície pública de showcase;
- apoiar a construção de um portfólio técnico verificável.

## Resultado esperado

Responder perguntas como:

> Onde eu usei PostgreSQL?

> Que evidência mostra que eu sei trabalhar com testes?

> Por que determinada decisão arquitetural foi tomada?
