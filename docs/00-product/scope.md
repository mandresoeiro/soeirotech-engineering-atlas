# Escopo Inicial

## Dentro do MVP

- projetos;
- skills;
- relação projeto ↔ skill;
- contexto de aplicação das skills;
- evidências;
- decisões arquiteturais;
- showcase público;
- health check.

## Fora do MVP

- rede social;
- marketplace;
- pagamentos;
- gamificação;
- IA generativa;
- notificações;
- aplicativo mobile;
- microserviços;
- analytics avançado.

Itens fora do MVP só entram quando houver problema real, prioridade e contribuição clara para o
portfólio técnico ou para a rastreabilidade de competências.
