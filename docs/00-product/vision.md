# Visão do Produto

## Produto

SoeiroTech Engineering Atlas.

## Visão

Uma plataforma para organizar a evolução prática de um desenvolvedor por meio da relação entre
projetos, skills, contexto de aplicação e evidências verificáveis.

O produto também funciona como portfólio técnico e como sistema de rastreabilidade de
competências.

## Não é

O produto não é uma cópia de cursos, disciplinas ou aulas.

## Princípio

**Projeto -> Skill -> Contexto -> Evidência.**

Estudo fornece conhecimento. Projeto fornece contexto. Evidência demonstra competência.
