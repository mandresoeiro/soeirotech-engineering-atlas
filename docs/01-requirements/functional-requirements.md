# Requisitos Funcionais

Status:

- **Existente**: já possui implementação inicial no sistema.
- **Planejado**: faz parte do escopo do produto, mas ainda precisa de implementação.

1. **RF-001 [Existente]** O sistema deve permitir cadastrar e acompanhar projetos.
2. **RF-002 [Existente]** O sistema deve permitir catalogar skills.
3. **RF-003 [Existente]** O sistema deve relacionar uma skill a um ou mais projetos.
4. **RF-004 [Existente]** O sistema deve registrar o contexto em que uma skill foi aplicada em um projeto.
5. **RF-005 [Existente]** O sistema deve registrar evidências associadas a um projeto.
6. **RF-006 [Existente]** O sistema deve permitir associar uma evidência a uma skill quando aplicável.
7. **RF-007 [Planejado]** O sistema deve registrar decisões arquiteturais vinculadas a projetos.
8. **RF-008 [Existente]** O sistema deve disponibilizar uma página pública inicial de showcase.
9. **RF-009 [Existente]** O sistema deve disponibilizar um endpoint de health check.

O fluxo funcional principal é: **Projeto -> Skill -> Contexto -> Evidência**.
