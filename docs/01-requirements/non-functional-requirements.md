# Requisitos Não Funcionais

Status:

- **Existente**: já orienta a implementação atual do projeto.
- **Planejado**: será exigido conforme a funcionalidade correspondente existir.

1. **RNF-001 [Existente] Segurança** Segredos não devem ser versionados.
2. **RNF-002 [Planejado] Segurança** Autorização deve ser validada no servidor quando houver áreas protegidas.
3. **RNF-003 [Existente] Qualidade** O projeto deve manter TypeScript em modo estrito.
4. **RNF-004 [Existente] Qualidade** Mudanças críticas devem possuir teste automatizado adequado.
5. **RNF-005 [Existente] Manutenção** Decisões arquiteturais relevantes devem ser registradas em ADR.
6. **RNF-006 [Existente] Operação** O ambiente local deve subir via Docker Compose.
7. **RNF-007 [Existente] Portabilidade** Configurações sensíveis devem ser fornecidas por variáveis de ambiente.
8. **RNF-008 [Planejado] Privacidade** O showcase público não deve expor dados privados.
9. **RNF-009 [Planejado] Rastreabilidade** Relações entre projeto, skill, contexto e evidência devem ser preservadas de forma consultável.
