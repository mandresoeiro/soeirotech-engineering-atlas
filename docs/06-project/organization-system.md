## Notion

Usar somente como **painel**:

```text
Hoje
Roadmap
Backlog
Estudos
TCC
Evidências
Links para GitHub
```

Não copiar código inteiro para o Notion.

## Caderno físico

Usar para dominar o assunto:

```text
O que é?
Onde está no projeto?
Por que usamos?
Trecho pequeno de código
Minha explicação
Como foi testado?
```

## Regra

> Uma informação deve possuir um local oficial. Evitar cópias espalhadas.
