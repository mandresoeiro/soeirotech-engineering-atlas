# Riscos

| Risco | Impacto | Mitigação |
| --- | --- | --- |
| Transformar o projeto em cópia de aulas | Alto | Exigir problema/requisito antes de cada feature. |
| Overengineering | Alto | Modular monolith e ADR para grandes mudanças. |
| Adicionar muitas tecnologias | Alto | Manter stack principal estável. |
| Acumular features sem concluir | Alto | Trabalhar por fases pequenas e Definition of Done. |
| Expor dados privados no showcase | Alto | Separar explicitamente superfície pública e privada. |
| Documentação ficar desatualizada | Médio | Atualizar docs junto com mudanças relevantes. |
| Duplicação de documentação | Médio | Manter uma fonte oficial por informação. |
