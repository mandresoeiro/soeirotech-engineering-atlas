# Case Study — SoeiroTech Engineering Atlas

## Problema

Há diferença entre estudar uma tecnologia e demonstrar onde ela foi realmente aplicada.

## Solução

O Engineering Atlas conecta projetos, skills, contexto de aplicação, decisões e evidências.

## Tecnologias atuais

- TypeScript
- Next.js
- PostgreSQL
- Prisma
- Docker
- Zod
- Vitest

## Ferramentas planejadas / próximos passos

- Playwright
- GitHub Actions

## Decisão arquitetural principal

Começar como modular monolith para manter simplicidade e coerência com o estágio do produto.
