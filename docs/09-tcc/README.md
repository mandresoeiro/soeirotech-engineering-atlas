# TCC — SoeiroTech Engineering Atlas

🎓[COURSE] Esta pasta será construída junto com o projeto.

## Título provisório

SoeiroTech Engineering Atlas: uma plataforma para rastreabilidade de competências, decisões
técnicas e evidências em projetos de software.

## Diretriz

O TCC será desenvolvido junto com a evolução real do produto.

As fontes para a escrita serão `docs/`, testes, ADRs, código e evidências produzidas no projeto.

Capítulos não devem afirmar funcionalidades ainda não implementadas.

## Estrutura prevista

```text
01-tema.md
02-problema.md
03-justificativa.md
04-objetivos.md
05-fundamentacao.md

13-referencias.md
```

## Regra

Não escrever capítulos grandes de uma vez.

> Projeto → aprendizado → teste → evidência → texto do TCC.
