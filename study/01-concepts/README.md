# 01 — Conceitos

📚[STUDY] 💡[IDEIA] 💻[CODE]

Cada conceito deve responder, de forma curta:

1. O que é?
2. Que problema resolve?
3. Como funciona?
4. Onde aparece no Engineering Atlas?
5. Como foi validado?
6. Qual trade-off ou limite importa?
7. O que preciso memorizar?

## Regra

Não marcar como dominado apenas porque o conceito aparece no código.
Domínio significa conseguir explicar sem copiar.
