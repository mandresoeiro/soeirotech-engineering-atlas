# 02 — Labs

🧪[TEST] 📚[STUDY] 💻[CODE]

Use para experimentos pequenos e descartáveis que respondem uma pergunta.

Exemplos:

- testar uma consulta Prisma;
- observar `null` x campo obrigatório;
- testar `include`;
- experimentar índice;
- testar Server Component;
- verificar comando Docker.

## Regra

Um Lab deve terminar com uma conclusão:

```text
pergunta → hipótese → experimento → resultado → aplicar ou não
```

Código de Lab não vira código do produto automaticamente.
